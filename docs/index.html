🚀 Быстрый старт

Этот инструмент поможет вам создать конфигурацию для прокси из ссылок формата VLESS, VMess, Trojan и Shadowsocks.

📋 Как использовать

1Скопируйте ссылку на прокси (одну или несколько)

2Вставьте ссылку в поле на главной странице

💡 Можно вставить несколько ссылок сразу — каждая должна быть с новой строки

3Нажмите кнопку «🔧 Сгенерировать конфиг»

4Скопируйте результат или сохраните в файл

🔗 Поддерживаемые протоколы

VLESS

Современный протокол с поддержкой Reality и TLS

vless://...

VMess

Протокол от V2Ray с шифрованием

vmess://...

Trojan

Лёгкий и быстрый протокол

trojan://...

Shadowsocks

Классический прокси-протокол

ss://...

📝 Примеры ссылок

VLESS Reality

vless://uuid@host:port?security=reality&pbk=...&sid=...&sni=...#Название

VMess

vmess://base64(json_config)

Trojan

trojan://password@host:port?security=tls&sni=...#Название

Shadowsocks

ss://base64(method:password)@host:port#Название

💡 Советы

✅ Используйте порт 443 — это обеспечивает лучшую совместимость и маскировку под обычный HTTPS-трафик
✅ Проверяйте ссылки — убедитесь, что ссылка скопирована полностью, без лишних пробелов
✅ Массовый импорт — можно вставить сразу 10-20 ссылок, каждая с новой строки

⚠️ Возможные проблемы

«Протокол не поддерживается» — убедитесь, что ссылка начинается с vless://, vmess://, trojan:// или ss://
«Неверный формат ссылки» — ссылка повреждена или скопирована не полностью
«Ошибка JSON» при загрузке файла — файл повреждён или имеет неправильную структуру

📁 Формат файла конфигурации

Сохранённый файл имеет структуру JSON:

{ "outbounds": [ { "tag": "название-прокси", "protocol": "vless", "settings": { ... }, "streamSettings": { ... } }, { "tag": "direct", "protocol": "freedom" }, { "tag": "block", "protocol": "blackhole" } ] }
