🚀 Quick Start

This tool helps you create proxy configuration from VLESS, VMess, Trojan, and Shadowsocks URLs.

📋 How to Use

1Copy the proxy link (one or multiple)

2Paste the link into the field on the main page

💡 You can paste multiple links at once — each should be on a new line

3Click the button "🔧 Generate Config"

4Copy the result or save to file

🔗 Supported Protocols

VLESS

Modern protocol with Reality and TLS support

vless://...

VMess

V2Ray protocol with encryption

vmess://...

Trojan

Lightweight and fast protocol

trojan://...

Shadowsocks

Classic proxy protocol

ss://...

📝 Example Links

VLESS Reality

vless://uuid@host:port?security=reality&pbk=...&sid=...&sni=...#Label

VMess

vmess://base64(json_config)

Trojan

trojan://password@host:port?security=tls&sni=...#Label

Shadowsocks

ss://base64(method:password)@host:port#Label

💡 Tips

✅ Use port 443 — this ensures better compatibility and masks traffic as regular HTTPS
✅ Check your links — make sure the link is copied completely, without extra spaces
✅ Bulk import — you can paste 10-20 links at once, each on a new line

⚠️ Troubleshooting

"Protocol not supported" — make sure the link starts with vless://, vmess://, trojan://, or ss://
"Invalid URL format" — the link is corrupted or incomplete
"JSON error" when loading file — the file is corrupted or has wrong structure

📁 Configuration File Format

Saved file has JSON structure:

{ "outbounds": [ { "tag": "proxy-name", "protocol": "vless", "settings": { ... }, "streamSettings": { ... } }, { "tag": "direct", "protocol": "freedom" }, { "tag": "block", "protocol": "blackhole" } ] }
